# HS.12.5 Demo Stems

Placeholder music beds for the Story Experience demo player.

| Stem | Asset | Mapped from presentation purpose |
|------|-------|----------------------------------|
| quiet | `quiet.wav` | opening, uncertainty |
| tension | `tension.wav` | challenge |
| build | `build.wav` | decision |
| expansive | `expansive.wav` | resolution |
| resolve | `resolve.wav` | closing |

`turningPoint` maps to intentional silence (no stem).

These files are **presentation-layer only**. The `StoryExperiencePlan` never
names audio files. Replace the WAVs later without changing the domain schema.

Generated as short sine tones for deterministic demo/tests. Not production music.
